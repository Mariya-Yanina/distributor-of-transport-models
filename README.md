## Аналіз продажів транспортної компанії
# Опис проєкту

Цей проєкт присвячений аналізу даних транспортної компанії з метою виявлення ключових факторів, що впливають на дохід, попит та ефективність бізнесу.

У ноутбуці виконано дослідження продажів, часових закономірностей, популярності послуг та поведінки клієнтів.

# Цілі аналізу

Проаналізувати динаміку продажів

Визначити найбільш прибуткові послуги

Виявити пікові періоди активності

Дослідити структуру доходів

Знайти інсайти для оптимізації бізнесу
